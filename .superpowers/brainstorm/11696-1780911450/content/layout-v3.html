图片处理方案

// 图片上传流程
1. 用户选择图片 → FileReader 读取为 base64
2. Canvas 压缩至 300×300，质量 0.7
3. 压缩后的 base64 存入 rewardRules[id].image
// 存储估算
· 300×300 JPEG @ 0.7 ≈ 15-30KB
· 10 条奖励规则 ≈ 150-300KB（远低于 5MB 限制）
// 降级处理
· 无图片时显示默认 🏆 图标
· 图片加载失败时回退到默认图标
