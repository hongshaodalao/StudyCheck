# 学习打卡 Web 应用设计文档

## 概述

一款面向学生的学习打卡 Web 应用。学生每天完成英语、数学、语文三个科目的打卡，三科全部完成才算当天完成。家长通过密码保护的设置界面管理奖励规则和数据。应用完全本地运行，数据存储在浏览器 localStorage 中。

遵循 PlayStation 设计语言（见 DESIGN.md）：深色画布为主背景、PlayStation Blue（#0070d1）强调色、8px 圆角卡片、药丸按钮。

## 技术方案

- **架构**：纯静态 HTML + CSS + JS，无需构建工具，直接浏览器打开
- **数据存储**：localStorage（~5MB 限制，对打卡数据绰绰有余）
- **应用模式**：单页应用（SPA），JS 控制视图切换
- **图片处理**：FileReader + Canvas 压缩至 300×300，JPEG 质量 0.7

## 数据模型

### 打卡记录

```
key: "checkins"
value: {
  "2026-06-08": { "english": true, "math": true, "chinese": true },
  "2026-06-07": { "english": true, "math": false, "chinese": true }
}
```

日期格式为 YYYY-MM-DD。每个科目值为布尔类型。三科全为 true 时该天计为"完成"。

### 奖励规则

```
key: "rewardRules"
value: [
  {
    "id": "r1",            // 唯一 ID（时间戳生成）
    "days": 10,            // 累计完成天数阈值
    "reward": "看一集动画片", // 奖励内容描述
    "image": "data:image/jpeg;base64,..." // 可选，base64 图片
  }
]
```

### 奖励记录

```
key: "rewardHistory"
value: [
  {
    "achievedAt": "2026-06-08",  // 达标日期
    "days": 10,                  // 对应天数阈值
    "reward": "看一集动画片",      // 奖励内容快照
    "image": "data:image/jpeg;base64,..." // 图片快照
  }
]
```

### 家长密码

```
key: "parentPassword"
value: "123456"   // 默认密码，字符串存储
```

## 页面结构

三个主视图，通过导航切换：

### 1. 打卡页（首页）

- 显示当前日期（年月日 + 星期）
- 三个科目卡片：英语 📚、数学 📐、语文 📖
- 每个科目显示勾选状态（圆圈 + 勾号）
- 点击科目切换完成/未完成状态
- 三科全部勾选后，自动标记当天为"已完成"，无需额外按钮确认
- 已完成状态下，科目勾选锁定不可更改，底部显示"✅ 今日已完成"状态文字
- 未完成状态下，底部显示灰色"完成全部科目后自动打卡"提示文字

### 2. 记录页（日历视图）

- 月历展示，左右切换月份
- 日期格子状态：
  - 普通完成日：PlayStation Blue 圆形背景
  - 获得奖励日：PS Plus 金色渐变圆（#ffce21 → #ee8e00）+ 🏆 图标
  - 今天：PlayStation Blue 圆形边框高亮
  - 未完成：默认文字颜色
- 点击奖励日期 → 弹出奖励详情弹窗
- 弹窗内容：
  - 有图片时展示图片
  - 无图片时显示默认 🏆 图标
  - 日期、累计天数、奖励内容
  - 距下一个奖励还需多少天
- 图例说明
- 底部统计：本月完成天数、累计完成天数

### 3. 设置页（密码保护）

**进入方式**：点击设置导航 → 弹出密码输入框 → 验证通过后显示设置内容

**密码管理区块**：
- 当前密码、新密码、确认新密码输入框
- "修改密码"按钮
- 校验：当前密码正确、两次新密码一致、新密码非空

**奖励规则区块**：
- 规则列表，每条显示：缩略图（有图时）/ 默认图标 + 天数 + 奖励描述
- 每条规则有"编辑"和"删除"操作
- "+ 添加"按钮
- 编辑/添加表单：
  - 累计打卡天数（数字输入）
  - 奖励内容（文本输入）
  - 奖励图片（可选，点击上传区域选择图片）
  - 上传后显示预览缩略图 + 文件大小 + 移除按钮
  - 保存 / 取消按钮

**数据管理区块**：
- "清除所有打卡和奖励记录"按钮（红色，Warning 色 #c81b3a）
- 二次确认弹窗
- 清除后同时删除 checkins、rewardHistory（保留 rewardRules 和 parentPassword）

## 奖励计数逻辑

1. 统计所有"三科全部完成"的天数 → `completedDays`
2. 遍历 `rewardRules`，按 `days` 升序排列
3. 对每条规则，检查 `completedDays >= rule.days` 且 `rewardHistory` 中无该规则已达标记录
4. 满足条件时，打卡页自动弹出奖励达成庆祝弹窗（含图片和奖励描述），并写入 `rewardHistory`
5. 日历渲染时，将 `rewardHistory` 中的日期标记为金色奖励日
6. 点击普通完成日（蓝色圆）无额外交互；点击奖励日（金色圆）弹出奖励详情弹窗

## 图片处理流程

1. 用户选择图片 → `FileReader.readAsDataURL()` 读取为 base64
2. 创建 `Image` 对象加载 base64
3. 创建 Canvas（300×300），`drawImage` 缩放绘制
4. `canvas.toDataURL('image/jpeg', 0.7)` 输出压缩后的 base64
5. 存入 `rewardRules[id].image`
6. 奖励达标时，快照到 `rewardHistory` 对应记录

存储估算：300×300 JPEG @ 0.7 ≈ 15-30KB/张，10 条规则 ≈ 150-300KB。

## 响应式设计

遵循 DESIGN.md 的断点系统：

| 断点 | 宽度 | 布局变化 |
|---|---|---|
| desktop | ≥1024px | 顶部水平导航，打卡页双栏（左打卡 + 右日历/奖励） |
| tablet | 768-1023px | 顶部导航收窄，打卡页单栏 |
| mobile | <768px | 底部标签导航，所有页面单栏 |

### 手机端（<768px）

- 底部三标签导航：打卡、记录、设置
- 打卡页：单栏，科目卡片纵向排列
- 日历视图：全宽月历
- 设置页：单栏表单

### PC 端（≥1024px）

- 顶部水平导航栏
- 打卡页：左侧打卡卡片 + 右侧日历预览和奖励进度
- 记录页：居中月历，左右切换
- 设置页：居中卡片布局

## 设计规范

从 DESIGN.md 继承：

- **主背景**：`#000000`（canvas-dark）
- **卡片背景**：`#181818`（surface-dark-card）
- **强调色**：`#0070d1`（primary）— 按钮、勾选、当前日期
- **奖励色**：`#ffce21 → #ee8e00`（PS Plus 金色渐变）— 奖励标注
- **危险色**：`#c81b3a`（warning）— 清除数据按钮
- **卡片圆角**：`8px`（rounded.md）
- **按钮圆角**：`9999px`（rounded.full，药丸形）
- **输入框圆角**：`4px`（rounded.sm）
- **字体**：PlayStation SST → Roboto / Inter 替代
- **显示标题**：weight 300（light）
- **按钮文字**：weight 700（bold）
- **正文**：18px / weight 400 / line-height 1.5
- **间距系统**：基于 8px，使用 4/8/12/16/24/32/48/96px

## 不做的事

- 不需要后端服务器
- 不需要用户注册/登录系统（仅家长密码保护）
- 不需要学习时长记录
- 不需要科目内容记录
- 不需要多用户支持
- 不需要数据导出/导入
